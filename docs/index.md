# English Reading Notes

This site collects **technical English reading notes** produced from GitHub repositories.

Each note takes one repository as its starting point and turns the parts worth reading
closely — the README, the design documents, the source comments, and the discussion in
issues and pull requests — into a single continuous English text, keeping the vocabulary
and phrasing that a technical reader is expected to know.

## What is here

- Notes grouped by the year and month in which the repository was read
- Original English prose rather than translated summaries
- A link back to the upstream repository in every note
