# Reading Archive

This is the archive of every reading note on the site.

Notes are stored as plain Markdown files under `docs/readings/`, one file per
repository:

```text
docs/readings/YYYY/MM/<repository-name>.md
```

`YYYY` and `MM` are the year and month in which the repository was read, so the folder
structure itself is the reading history. Files are picked up automatically when the site
is built, which means a new note shows up in the navigation as soon as its Markdown file
is committed — there is no separate list to keep up to date.

## A note usually contains

- A short introduction to the repository and the problem it solves
- Selected passages from its documentation and source, rewritten as continuous English
- The technical terms and idioms worth remembering, in the context where they appear
- A link to the upstream repository
