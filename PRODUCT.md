# Product

## Register

product

## Users

People reading technical English notes while learning software architecture and implementation vocabulary. They need a calm, focused reading flow that lets them move from the English overview to sentence-level explanations and useful expressions.

## Product Purpose

English Reading Notes turns repository analysis into a browsable study archive. Success means readers can understand the main technical passage, compare English with Chinese explanations, and review reusable expressions without the site feeling like a generic documentation portal.

## Brand Personality

Focused, editorial, quietly encouraging. The interface should support concentration and comprehension rather than compete with the text.

## Anti-references

Avoid oversized documentation-page titles, dense undifferentiated Markdown, weak card boundaries, decorative gradients, and noisy dashboard-style UI.

## Design Principles

- Make the English passage the primary reading experience.
- Turn sentence explanations into distinct, reusable learning units.
- Preserve source notes while adapting legacy formats at the website layer.
- Keep visual emphasis restrained so hierarchy supports comprehension.

## Accessibility & Inclusion

Maintain readable contrast, responsive layouts, keyboard-friendly links, reduced-motion compatibility, and no horizontal overflow on small screens except intentional code blocks.
